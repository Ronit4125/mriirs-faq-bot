# University FAQ Bot (MRIIRS)

A single-page FAQ chatbot for Manav Rachna (MRIIRS) students. Answers admissions, fees, exams, attendance, hostel and contact questions from an editable knowledge base.

- Open `index.html` in a browser, or host it with GitHub Pages.
- Edit the knowledge base inside the page ("Edit knowledge base"); changes are saved in your browser.
- Fees and hostel costs are from third-party listings. Verify them on manavrachna.edu.in.
